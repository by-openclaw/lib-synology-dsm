## DSM Known Issues (tracked separately)

| ID | Finding | DSM Version | Status | Tracking |
|---|---|---|---|---|
| DSM-1 | `SYNO.Core.Group.member_list` returns error 103 on ALL inputs — member read-back impossible | DSM 7.1.1-42962 Update 9 | ⏳ Pending DSM upgrade | platform-setup#54 |

**DSM-1 detail:**
Probed exhaustively with all parameter combinations (`name=`, `group_name=`, `group=`, `gid=`, no params).
Every combination returns `{"error": {"code": 103}, "success": false}`.
This is a regression in DSM 7.1.x — fixed in DSM 7.2.x.
Write operations (`SYNO.Core.Group set` with `members=[]`) work correctly throughout.
Impact: `add_member`/`remove_member` apply unconditionally when member list unreadable, return `warning` key.
Resolution: upgrade DSM to 7.2.x (see platform-setup#54).
